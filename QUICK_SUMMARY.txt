🎯 الهدف الرئيسي:
   بوت تداول ذكي يحقق أرباح مستقرة مع حماية رأس المال

💰 رأس المال:
   $300 (65% Spot، 35% Futures)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✨ المميزات الرئيسية:

1️⃣ الذكاء الاصطناعي (Machine Learning)
   • Random Forest + Gradient Boosting
   • 50+ ميزة مستخرجة من البيانات
   • دقة: 70-80%
   • يتعلم من كل صفقة

2️⃣ 5 استراتيجيات متوازية
   • Momentum (الزخم)
   • Mean Reversion (العودة للمتوسط)
   • Breakout (الكسر)
   • Volume Profile (حجم التداول)
   • ML-Based (قائمة على الذكاء الاصطناعي)
   • دقة مجمعة: 70-85%

3️⃣ كشف وتجنب الفخاخ
   • 6 أنماط ذيول شموع
   • 6 أنماط حيتان
   • 5 درجات خطورة
   • فلاتر أمان مزدوجة

4️⃣ فهم نفسية الحيتان
   • صيد Stop Loss
   • الضخ والتفريغ
   • التجميع والتوزيع
   • الكسر الوهمي
   • الخداع
   • درجة نشاط (0-100)

5️⃣ تحليل دفتر الأوامر
   • نسبة البيع/الشراء
   • تركز الأوامر الكبيرة
   • حجم الفجوات
   • الضغط الشرائي/البيعي

6️⃣ بيانات CoinGlass
   • نسب التمويل
   • الفائدة المفتوحة
   • توزيع الأسعار
   • معنويات السوق

7️⃣ إدارة مخاطر فائقة
   • Circuit Breaker (إيقاف عند 5% خسارة يومية)
   • حساب حجم الصفقة الذكي
   • Stop Loss محمي
   • Trailing Stop Loss
   • فلتر الارتباط

8️⃣ تنبيهات Telegram فورية
   • صفقات جديدة
   • صفقات مغلقة
   • تنبيهات فخاخ
   • إحصائيات يومية

9️⃣ حوار ذكي باللغة العربية
   • الإجابة على الأسئلة
   • شرح الإشارات
   • تقديم التوصيات

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📊 الأداء المتوقع:

نسبة الفوز: 65-75%
دقة التنبؤ: 75-85%
العائد الشهري: 8-12%
نسبة المخاطرة/العائد: 1:2.5 أو أفضل

مثال على الأداء:
• الشهر 1: $300 → $330 (10%)
• الشهر 2: $330 → $365 (10.6%)
• الشهر 3: $365 → $405 (10.9%)
• بعد 3 أشهر: $405 (35% عائد)

├─ Multi-Strategy Engine (5 استراتيجيات)
├─ Wick Detection Engine (كشف الذيول)

├─ CoinGlass API (المعنويات)
├─ Etherscan V2 API (الحيتان)
└─ Telegram API (التنبيهات)
